About 

            Cloud computing means using servers, storage and software over the internet instead of owning hardware.
            Cloud architecture is the design that links these services into a scalable, secure and reliable system.
            Platforms like Google Cloud, AWS and Azure power it, with models like IaaS, PaaS and SaaS.
